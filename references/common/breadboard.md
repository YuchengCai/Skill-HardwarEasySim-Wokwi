# Breadboard — 面包板使用指南 (v2)

> 系统级通用面包板知识（适用于所有板型）。
> v2 重写：位置关系为核心、$bb 前提、跳线必须、旋转灵活。
> 验证：真实用户手动布线模板（complex-system-user-wiring.json）。

## 第 1 层：位置关系（核心！）

元件放在面包板**周围**（上方/下方/两侧），**相对位置要清楚**：

```
布局示意（纵向）：
  [LED/传感器]    ← 面包板上方（信号区）
  [面包板 bb1]    ← 中间
  [按钮/电阻]     ← 面包板下方（操作区）
  [Arduino 板]    ← 更下方

要点：
  - 元件位置 ↔ 面包板孔位要有对应关系（这是 $bb 能用的前提）
  - 尺寸选择（half/full）是为了容纳元件数量，不是硬性
  - 旋转（元件/板子/面包板）是为了配合布局线序，不是硬性
  - 真实场景由使用者交互调整最终位置
```


## 孔位坐标系统（实测反推，wokwi 编辑器标尺验证）

**方向修正（重要）：数字 = 水平方向，字母 = 垂直方向！**

孔位命名 `<数字><半区>.<字母>`，如 `30b.h` = 数字 30、下半区 b、字母 h：

```
数字 1..30  → 水平（x），间距 9.6，首孔偏移 10.6
字母        → 垂直（y），间距 9.6，首行偏移 9
半区 t/b    → 上/下半区（中间隔 trench），b 在 t 下方偏移 19.2
```

**半区每侧只有 5 个孔（重要！）**：

```
t 半区 = 字母 a-e   （5 孔，内部连通）
b 半区 = 字母 f-j   （5 孔，内部连通）
```

- 内部连通 = **同行 + 同半区 + 同 5 孔组**
- 跨半区（t↔b）**或**跨组（a-e↔f-j）都不连通，必须跳线（或用跨 trench 的元件桥接，如电阻）

> ⚠️ 常见错误：把线接到 `30b.a` 或 `30t.j`（b 半区没有 a，t 半区没有 j）。
> 这类「错误组」孔位不是有效孔，线会落到离元件很远/不存在的孔 → 视觉上「消失」。
> `freeHole` 只应在所属半区的 5 个字母里选，并优先选「离元件引脚最近的空闲孔」。

### 半板尺寸（wokwi-breadboard-half）

```
宽 313.6 × 高 166（画布 px，实测校准，与 layout-generator.js / optimize-wiring.js 一致）
```

### 孔位 → 画布坐标公式

**未旋转（rotate 0）**，面包板左上角 (left, top)：

```
x(n)        = left + 10.6 + (n - 1) × 9.6
y(L, half)  = top  + 9    + idx(L) × 9.6 + (half === 'b' ? 19.2 : 0)
             idx: a=0, b=1, ..., j=9
```

**旋转 180（rotate 180，本 skill 默认）**：

```
rx(n)       = left + 303 - (n - 1) × 9.6      // = left + 313.6 - 10.6 - (n-1)*9.6
ry(L, half) = top  + 157 - idx(L) × 9.6 - (half === 'b' ? 19.2 : 0)
```

### 电源轨

```
tp.<n> 上正轨 / tn.<n> 上负轨 / bp.<n> 下正轨 / bn.<n> 下负轨
```

**轨列几何**（用户悬停孔名 + dragramtest 模板精确对齐实测确认）：

```
位置号有效范围 1..25（>25 的引用 Wokwi 不渲染 → 线消失）
轨孔 = 5 组 × 5 孔，组间多 1 个孔距（9.6px）间隙（标准面包板结构）
rotate 180 画布坐标：x(n) = left + 293.0 - (idx + floor(idx/5)) × 9.6, idx = n-1
锚点验证：bn.23 正对 LED1 阴极（悬停确认）；bn.25/bn.22 与模板 led1/2:C 精确重合
```

> 四条轨共用同一 x 模型 → tn.n 与 bn.n 同 x，轨间跳线可做成纯竖直（tn.2→bn.2）。

**轨行几何（y，rotate 180 视觉位置，实测校准）**：

```
bn = top + 5.6   视觉顶负轨（紧贴顶边）
bp = top + 15.2  视觉顶正轨（bn 下方 1 个孔距）
tn = top + 156   视觉底负轨
tp = top + 162   视觉底正轨
```

> 轨 y 与主区孔距同为 9.6。锚点验证：按钮 GND 线直落 bn 时无折回 → bn=top+5.6（不是 top+4）。

### 元件 $bb 插接配方（实测校准，引脚 → 孔位）

| 元件 | rotate | 引脚 → 孔位 |
|------|--------|------------|
| 按钮 | 90 | 1.r→`n`t.b, 2.r→`n+2`t.b, 1.l→`n`b.g, 2.l→`n+2`b.g |
| 电阻 | 90 | 1→`n`b.g, 2→`n`t.c |
| DHT22 | 0 | GND→`n`b.i, NC→`n+1`b.i, SDA→`n+2`b.i, VCC→`n+3`b.i |
| LED | 0 | **不用 $bb**，用可见线 A→孔、C→负轨 |

> 元件位置 = 锚定引脚所在孔位 - 该引脚的 `_rot90` 偏移（见 `pins.json`），这样引脚精确落在孔位上、$bb 渲染才吸附。

## 第 2 层：$bb 语义（虚拟连接）

```
$bb = 元件引脚 → 面包板孔的【虚拟连接】（隐藏线）

["btn1:1.l", "bb1:16b.g", "", ["$bb"]]

只需写两端：
  元件引脚（btn1:1.l）
  面包板孔位（bb1:16b.g）

关键前提：元件位置和面包板孔位已对应
  → 否则逻辑上连接了，视觉上没连接（元件悬空/线悬空）

$bb 适用于：按钮、传感器（DHT 等）、电阻（跨槽）
不适用于：LED（用普通线连孔，可见）、蜂鸣器（直连板子）
```

## 第 3 层：电源架构（必须的跳线！）

跳线是电路真正连通的**必要条件**，必须写：

```
① 板子 → 面包板电源轨（可见线）
   ["uno:5V", "bb1:tp.10", "red", [...]]
   ["uno:GND.2", "bb1:tn.10", "black", [...]]

② 轨间跳线（上下轨连通）
   ["bb1:tp.1", "bb1:bp.1", "red", [...]]   上正 → 下正
   ["bb1:tn.1", "bb1:bn.1", "black", [...]] 上负 → 下负

③ 电源轨 → 元件区（元件 VCC 供电）
   ["bb1:tp.9", "bb1:11b.f", "red", ["v0"]] 正轨 → 元件行

④ 元件区 → 电源轨（元件 GND 回流）
   ["bb1:16b.h", "bb1:bn.13", "green", ["v0"]] 元件行 → 负轨
   ["bb1:21b.h", "bb1:bn.17", "green", ["v0"]]

→ 没有跳线 = 元件没通电（逻辑连了电路没通）
```

> 元件级偏好（LED↔电阻同列、按钮对侧、各元件的 $bb 配方与接线）**统一见 `layout-cards/`**，按当前项目用到的元件按需读取。

## 面包板接线惯例（灰度规则：脚本已按默认实现，模型可按场景变通）

> 硬几何（孔位/轨坐标）见上文；下表是**面包板级**软偏好，不是硬约束。
> 脚本 `layout-generator.js` 已按这些默认实现；模型在特殊场景改意图（intent）覆盖即可，**坐标/孔位始终由脚本推导**。

| 惯例 | 默认做法 | 为什么 | 何时不适用 |
|------|---------|--------|-----------|
| **轨线从相邻孔出线** | $bb 引脚插孔后，从**同行空闲孔**出线接轨（不从引脚直出） | 一孔一接、线不叠在引脚上 | 引脚非 $bb（如 LED 阴极直连轨） |
| **GND 就近 + 一孔一接** | 主线接最近端口 tn.1，跳线 tn.2→bn.2（不共孔） | 最短，且遵循一孔一接 | 板子方位不同则换最近端口 |

## 第 5 层：调整手段（非硬性）

```
尺寸选择：
  wokwi-breadboard-half → 元件 ≤ 8（多数场景）
  wokwi-breadboard     → 元件多/需要大区域

旋转：
  面包板 rotate 180 → 改变孔位方向（配合布局）
  元件 rotate 90/270 → 改变引脚方向（配合线序）
  板子 rotate → 改变引脚朝向（配合整体布局）

验证：
  真实场景由使用者交互调整（拖拽/旋转看效果）
  规则提供"合理默认"，最终以模拟效果为准
```

## 元件引脚名（用户模板确认）

```
board-ssd1306（OLED，I2C）：SDA / SCL / VCC / GND
  （注意：不是 wokwi-ssd1306 的 DATA/CLK/VIN！用 board-ssd1306）

wokwi-breadboard-half 孔位：
  元件区：<行><t/b>.<列>（t=上半区，b=下半区；列 a-j）
  电源轨：<t/b><p/n>.<位置>（tp=上正、tn=上负、bp=下正、bn=下负）
```
