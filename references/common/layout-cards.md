# Layout Cards — 按元件类型的布局/接线偏好卡

> 系统级布局偏好，按元件类型组织。生成 `diagram.json` 时，**只查当前项目实际用到的元件**对应的卡片（按需加载，不整份读）。
> 灰度规则：默认这样做；脚本兜底；场景特殊时改意图（intent）覆盖，坐标始终由脚本推导。
> 验证状态：LED / 电阻 / 按钮 = 本轮面包板布线打磨已 Wokwi 确认；DHT / OLED / 蜂鸣器 = 来自 dragramtest 用户模板，待生成器覆盖验证。

## LED 卡

- **与配对电阻同列**：LED 放其配对电阻正上方同列，A 脚 x 对准电阻列 → 信号线竖直最短
- **接线**：A ← 电阻（普通可见线）；C → bn 负轨（普通可见线，直连轨）
- **不用 $bb**：LED 不插板，悬浮在面包板上方
- **重叠检测**：视觉本体 ~16px 圆泡，检测用 20×20（不是 40×50 容器）
- 何时不适用：无配对电阻；该列被占；LED 数超可用列

## 电阻卡

- **rotate 90 跨槽**：`1→n b.g`（b 半区）、`2→n t.c`（t 半区），$bb 插接
- **引脚方向**：板子在下 → 信号接 t 半区 2 脚；LED 在上 → 接 b 半区 1 脚（信号线不穿电阻本体）
- 何时不适用：板子/元件方位不同时按「最近原则」对调两脚

## 按钮卡

- **对侧接线**：信号接一侧、GND 接另一侧（如信号 2.r、GND 1.l）
- **顺序**：btn1 左、btn2 右，与 LED1/LED2 左右顺序一致
- **GND 出线**：$bb 插孔后，从**同行相邻孔**出线接负轨（不从引脚直出）
- **$bb 四脚**：1.r/2.r→t 半区、1.l/2.l→b 半区（机械固定，即便只用其中两脚）
- 何时不适用：单侧更省线时可同侧；语义顺序不同时换顺序

## DHT22 卡（模板）

- **$bb 连 b 区 4 孔**：GND→`n`b.i、NC→`n+1`b.i、SDA→`n+2`b.i、VCC→`n+3`b.i
- **电源**：VCC 经跳线接正轨（tp→元件行），GND→负轨
- **数据**：SDA 所在行 → 板子数据引脚（普通可见线）

## OLED 卡（board-ssd1306，I2C）（模板）

- **SDA/SCL 直连板子**（如 A4/A5），VCC→正轨、GND→负轨
- ⚠️ 用 `board-ssd1306`（引脚 SDA/SCL/VCC/GND），**不是** `wokwi-ssd1306`（DATA/CLK/VIN）

## 蜂鸣器卡（模板）

- 直连板子：`uno:<pin>` → bz1:1；bz1:2 → bn 负轨
- 不用 $bb（放板子旁）
