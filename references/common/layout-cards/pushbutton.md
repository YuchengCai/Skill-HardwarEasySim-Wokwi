# 按钮卡（wokwi-pushbutton）✅

- **电气端子（判断接线的前提）**：四脚分两组端子——`1.l ↔ 1.r`（端子 1）、`2.l ↔ 2.r`（端子 2）；按下时端子 1 与端子 2 导通。**信号和 GND 必须接在不同端子上**（同端子 = 按下无效）。
- **$bb 四脚**：rotate 90，1.r/2.r→t 半区、1.l/2.l→b 半区（机械配方见 `../breadboard.md`；即便只用其中两脚，四脚都插以机械固定）
- **对侧接线（默认）**：信号接一侧、GND 接另一侧（如信号 `2.r` + GND `1.l` = 不同端子 + 分居两侧）
- **顺序**：btn1 左、btn2 右，与 LED1/LED2 左右顺序一致
- **GND 出线**：$bb 插孔后，从**同行相邻孔**出线接负轨（不从引脚直出）
- 何时不适用：单侧更省线时可同侧（如信号 `1.l` + GND `2.l`，**仍须不同端子**）；语义顺序不同时换顺序
