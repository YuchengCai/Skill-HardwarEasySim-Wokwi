# 走线思维：人类手画 vs 脚本连线（2026-11-07，T12 实录归纳）

> 用户问题："让脚本直接连线，思路和人类手画时不太一样。是不是需要修正模型的思考思路或脚本的安排思路？"
> 答案：是的。本质差异是**顺序**：人先规划路网再逐线接驳（top-down），脚本逐线生成再全局协调（bottom-up）。

## 1. 人类怎么画（从 ref1/ref2 与真实接线归纳）

1. **基础设施先行**：板 + 面包板定锚，先铺电源（喂轨/列总线）——先把"高速公路"修好。
2. **分股思考**：线不是一根根画的，是**一束束**画的——"这股电源走中间列、那股信号从模块左边出、板脚线从板底绕"。每股有自己的通道。
3. **就近接驳**：每根线找**离目标最近的可连接点**——已铺好的网就是现成入口（列孔/轨位）。
4. **一拐到位**：每根线几乎只有 1-2 个直角弯——人不会为难自己，画长绕线等于重画。
5. **孔是免费的接线柱**：线一多就借孔分摊、中继、换层，绝不硬挤一条通道。

## 2. 脚本现在怎么连（v2 实况）

1. 摆元件（分层排序——已经是人类式）。
2. **逐条连接独立决策**：每条线按几何类别选方法（直落/阶梯/绕板/上轨）。
3. 全局协调**后置且机械**：left-edge 塞车道、孔位就近挑——都在"逐线"框架里打转。

## 3. 差异的实证（本会话记录）

| 实验 | 结果 | 说明 |
|---|---|---|
| per-module 独立车道 | U1 交叉 9→32 变差 | 逐线层修补，破坏天然嵌套 |
| 全局 left-edge | 共线清零但交叉 +28 | 机械填塞不懂"分股" |
| **电源列总线（一网一列）** | 电源长线整体收短 | 唯一真正的"先规划"决策，效果最好 |
| 人眼抓出的问题（穿件/共线/拧束/孔冲突/断网） | 全部是全局协调层缺陷 | 逐线决策天然看不见 |

**结论：人类的第一根线就走在正确的通道上，因为通道在脑子里；脚本画完所有线才知道哪里挤。**

## 4. 修正：在「放置」与「逐线走线」之间加「通道规划层」

```
骨架（band） → 放置（分层） → 【通道规划：按网络分股，每股分配 y 带与转折区】 → 逐线走线（只在所属股的带内）
```

分股规则（脚本可算 + 模型可覆盖）：
- 每个电源族一股（列总线 + 跳线 + 馈线是一体的"路网单元"）；
- 每个模块的信号线一股（离体侧 + 束内次序 + 车道深度由引脚序决定）；
- 板脚线一股（绕板带）；
- 股间通道互不侵占 → 共线/交叉/拥挤在规划层就不发生，而不是事后协调。

## 5. 模型层的对应修正

模型在 intent 里应写**路网声明**（判断），而非只写连接列表：
```jsonc
"routing": {
  "buses": [ { "net": "GND", "via": "column 22t" } ],
  "bundles": [ { "from": "rfid1", "edge": "left" } ],
  "relays": [ { "signal": "A0", "via": "2b.i/j" } ]
}
```
不声明则脚本按几何默认分股。**分工不变：分股/通道是判断（模型），带内几何是计算（脚本）。**

## 用户手改 U2 电源架构实录（2026-11-07，人机对比黄金样本）

> 用户在浏览器里 15 分钟的修改，比生成器几轮迭代更简洁。存档 `zcode-analysis/U2-golden-power.json`。

### 用户的三个决策

| 网 | 用户的做法 | 生成器原来的做法 |
|---|---|---|
| **5V**（仅 2 参与者） | `uno:5V→30t.a` 馈电**进列** + `mux1:VCC→30t.e` 消费者同列——**单列即网，免轨免跳线** | 馈 tp 轨 + 消费者直连轨（多一层基础设施） |
| **3.3V**（3 消费者+列总线） | `uno:3.3V→tp.25` **端部馈电** + `tp.1→bp.1` **末端桥接两根正轨成一张网**（P1 的正确用法） | 绕边馈 bp（线长 700+） |
| **GND**（大网） | 馈电在轨**端部** tn.25、跳线在中段 tn.18→22t.a | 馈电在中段 tn.21 |

### 提炼成规则（进生成器）

- **R-按网选基础设施**：参与者 ≤2 → 单列即网（馈电与消费者同列，0 跳线）；
  参与者多 → 轨 + 列跳线；需要两轨可用 → 同极性末端桥接（tp↔bp 都为正时可桥）。
- **R-端部馈电**：馈电占轨的端位（n=25），中段留给跳线/消费者——轨的两端是"入口"。
- **R-同极双轨一张网**：tp/bp 同为正轨，可末端桥接成一张大网（不同电源网仍严禁互桥）。
