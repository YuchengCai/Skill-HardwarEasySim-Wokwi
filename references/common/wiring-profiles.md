# 输出档位（Wiring Profiles）与跳线台账

> 2026-11-13 讨论定稿。解决一个真实的分歧：
> **指标最优的画法 ≠ 现实中最合适的画法。**

## 0. 为什么需要"档位"

用户 2026-11-12 手画过一版**完全隔离 + 跳线矩阵**的 U3b：硬冲突 0、交叉 10（我们生成版 38）、
转弯 2.10（我们 3.00），但**连接数 29（我们 18）**、外框 721×605（我们 696×516）、
间距违规 38 组（真违规 2 组）。

**用户的判断（本档位的由来）**：
> 这种画法"在真正的现实环境中大概率不会完全这样做"——它只考虑元件与控制板跑通，
> 不考虑走线便捷度，也不考虑元件与连线在装置/产品内部的情况。

所以：**它是可选范式，不是默认**。skill 必须能按场景切换，并且**说清楚为什么这么画**。

## 1. 三个档位

| 档位 | 目标 | 典型场景 | 特征 |
|---|---|---|---|
| **`prototype`（默认）** | 视觉清晰、可读、易改 | 面包板原型、教学、Wokwi 仿真演示 | 共用轨/列；线数少；交叉中等；面积小 |
| **`matrix`（可选）** | 交叉最少、结构最规整 | 演示"最清晰走线"、评审、拓扑展示 | 母线中继列 + 一网一列 + 列↔列跳线；线数多；面积大 |
| **`device`（未实现，仅声明）** | 装配可行、可维护 | 产品内部/外壳内 | 线束、长度、固定、走线槽、维修可达性；**引擎目前不支持，必须显式声明不支持** |

**纪律**：引擎不得默默选择档位。intent 未声明时 = `prototype`；选 `matrix` 必须在 intent 写明
`routing.profile: "matrix"` + `reason`（一句话，例：`"评审需要最少交叉"`）。

## 2. `matrix` 档的触发与禁止条件

**建议触发**（全部满足才可选）：
1. 消费者 ≥3 的网 ≥2 个（存在天然的母线结构）；
2. 交叉主要来自"长横段 × 竖线"（而非引脚次序决定的①类）；
3. 列位容量够：需要的列数 ≤ 25（含母线列，块间留分隔列）；
4. 用户/场景明确"可读性 > 装配性"。

**禁止**：
- 列位不足（如 U2 那种 3 rfid × 4 网 + 母线 + 电源）；
- 多网共轨（电源脚稀缺）；
- 需要机械固定/线束管理（`device` 场景）；
- 用户要"少线/少跳线"。

## 3. 跳线台账（强制产出）

只要用了母线/中继/隔离列，**必须生成 `wiring-notes.md`**（人读），逐条说明：

```markdown
## 接线说明（自动生成）
### 网：I2C-SDA（绿）
- 母线中继列：`bb1:4t`（板脚 uno:A4 → 4t.a）
- 分发跳线：4t.b → 17t.a（下区中继列 17）→ 17t.d → 27t.d（mpu）、17t.e → 22t.d（rtc）、17t.c → 15b.f（oled）
- 作用：先把 SDA 收成一条母线，再在下半区中继，最后分发到各元件列
### 网：GND
- 板脚 → tn 轨（一根馈电）
- 隔离列：mpu 29t（tn.24→29t.a）、rtc 24t（tn.20→24t.a）、oled 12b（tn.10→12b.f）
- 作用：每元件独立接地列，避免共用列的孔位冲突
```

**字段来源**：`routing.relays[]`（已存在的 schema）+ 引擎实际落位。
**台账的价值**：使用者能看懂"为什么要多这些跳线"，也能按台账逐条手改。

## 4. 与 intent 的关系

`routing.relays[].role` 扩展取值：

| role | 含义 |
|---|---|
| `fanout` | 一脚多用扇出（原义） |
| `pass` | 过路（自己是消费者、信号不经 bb） |
| **`bus`** | **母线中继**：先收成一条母线列，再分发 |
| **`isolation`** | **隔离列**：某元件某网独占一列（避免与兄弟网共享列/行） |

`matrix` 档下，引擎应**校验**：每个 `bus` 声明是否真的有"母线列 → 分发跳线"两段；
每个 `isolation` 声明是否真的独占（不与其它网共列、孔位错行）。

## 5. 验收（matrix 档）

以用户手画版 `_evalt2` 为参照：

| 指标 | 目标 |
|---|---|
| 硬冲突 | 0（含方向提示） |
| 交叉 | ≤ 10 |
| 端点遮挡 | **0**（靠"同模块同侧列错行"消除掠过） |
| 间距 <9.6 | ≤ 2 组（真违规，非取整） |
| 连接数 | 允许 +60% |
| 台账 | 必须有且与落位一致 |
