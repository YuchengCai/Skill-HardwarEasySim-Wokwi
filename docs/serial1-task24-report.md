## 2. 修改内容（`scripts/optimize-wiring.js`）

- 新增 **线-已用孔端点保护**：从 `geometry.json`（含面包板 rotate 180）求已用孔中心，计算导线折线到孔中心最短距离。
  - `d < 4`（旧诊断口径，未校准）→ 新增硬冲突 `near-hole`（报告：连接号、两端引用、被影响孔、距离、阈值±1 待核实）；
  - `4 < d ≤ 60` → `[近孔复核]` 逐线最近孔清单（默认只列最近孔落在 4..11 的引线，`--near-hole-report` 列全部），明确「>阈值保留原走线」。
- 新增 **异线共线/近贴**：不同端点、不共享引脚的线对，同向分段求投影重叠；`gap≤0.5` 且重叠>2 → 硬冲突 `overlap-collinear`（合并同位置多段为总重叠）；`gap≤1` 且重叠>20 → `overlap-near`；报告位置（y/x 值）、间距、重叠长与两条线引用。
- 新增证据绑定行：图纸 `sha256` 摘要、坐标来源 `geometry.json`、阈值与待核实带、规则版本、覆盖范围（直段中心线；圆角/端部未覆盖）。
- 新类型纳入硬冲突分级（`SUMMARY_OUT` 与报告硬列表），`--fix` 不自动改写（保持作者判断）。
