## 4. 本轮顺带修复的真实缺陷（由陌生组合暴露）

1. `is(p,'resistor')` 子串匹配把 `wokwi-photoresistor-sensor` 误当电阻（用脚名 1/2 生成 $bb）→ 增加排除；
2. 无插接配方的 bb 元件被推入直连列表但 `placement` 未改 → 坐标停在 (0,0) 叠板角 → 显式回退 `placement='board'` 并告警；
3. 直连放置用 `p.placement==='bb'` 判断，未写 placement 的默认插接件被直连坐标覆盖 → 改为 `(p.placement||'bb')==='bb'` 跳过（同时修掉按钮 $bb 大幅错位）；
4. `near-hole` 未区分同网孔 → 用电气并查集跳过「同一网络内的已用孔」，消除同网邻孔误报（pin-conflict 的 22t.e 仍正确命中）。
